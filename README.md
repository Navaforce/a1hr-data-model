# A1 HR Demo: Data Model Review

Single-file review page (`index.html`) for the Air Force A1 HR Vision demo data model.

- Each section has Approve and Change checkboxes plus a comment box.
- State saves in the browser. Export JSON from the header, send the JSON back to David.
- No credentials in this repo. Scope and context: `docs/BRIEF.md`.

Field tables page at 20 per row set with a glowing pager. Each section collapses with its caret. Open Decisions has a comment box per decision (included in the JSON export under `decisions`).
